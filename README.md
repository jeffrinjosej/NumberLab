# NumberLab

NumberLab is a beginner-friendly C++ console application created while learning the fundamentals of C++ programming.

## Features

* **Number Analyzer**

  * Checks whether a number is positive, negative, or zero
  * Checks whether a number is even or odd

* **Multiplication Table**

  * Generates the multiplication table of a given number from 1 to 10

* **Pattern Studio**

  * Generates star patterns
  * Generates number patterns
  * Allows the user to choose the number of rows

## Concepts Used

* Variables and data types
* Input and output
* Operators
* Conditional statements
* `switch` statements
* `for` loops
* `do-while` loops
* Nested loops
* `break` statements
* User input and menu-driven programming
